# My Web Journey

A five-page English website for a Web Technology personal project.

## Pages

- `index.html` — Home and student experience
- `quotes.html` — Quotes and a quote button
- `contact.html` — Contact email
- `project.html` — Website building process
- `game.html` — A simple star game

## Run it in VS Code

Open this folder in VS Code. Install Live Server. Right-click `index.html` and choose **Open with Live Server**.

## Before GitHub Pages

Replace `YOUR-GITHUB-NAME` in the five HTML files with the real GitHub user name. Push this folder to its own public repository and enable GitHub Pages.
